# Tutoriel Vue.js 3 – Les fondamentaux avec CDN

Dans ce tutoriel, vous allez découvrir les principales fonctionnalités de Vue.js 3 en utilisant uniquement un fichier HTML et un CDN.
L'objectif est de comprendre comment Vue.js permet de créer des interfaces web interactives, sans avoir besoin de manipuler directement le DOM.

À la fin de ce tutoriel, vous saurez utiliser :
1. createApp() – créer une application Vue.
2. data() – définir les données de l'application.
3. methods – créer des fonctions.
4. computed – calculer des valeurs automatiquement.
5. v-if – afficher ou masquer des éléments.
6. v-for – parcourir une liste.
7. v-model – synchroniser les données et les champs de formulaire.
8. La gestion des événements – réagir aux actions de l'utilisateur.

# DOM
Document Object Model.
C'est la version vivante / manipulable du plan "static" html qui sera gardé en mémoire par le navigateur.
# CDN
Content Delivery Network.
C'est un réseau de serveurs qui stock et distribue des fichiers statics (genre html). On va copier le lien dans le code pour éviter de devoir installer les outils qui vont avec Vue.js
