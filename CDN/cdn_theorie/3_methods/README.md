# 3. methods – Définir des fonctions

La prorpiété methods permet de définir des fonctions utilisables dans l'application.

`methods` contient les fonctions de mon application
`increaseQUantity()` augmente la quantité
`decreaseQuantity()` diminue la quantité
`this.quantity` permet d'accéder à la propriété `quantity` définie dans data().

`this` fait donc référence à l'instance du composant Vue.
