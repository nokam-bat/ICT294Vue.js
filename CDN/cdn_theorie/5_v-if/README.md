# 5. v-if – Afficher ou masquer des éléments selon condition

v-if est une directive qui permet d'afficher un élément HTML UNIQUEMENT si une condition est vrai.
(vrai if)

On peut aussi utiliser v-else-if pour tester de multiples conditions.

*à retenir* v-if ajoute/retire réellement l'élément du DOM
Il existe aussi v-show qui masque un élément avec CSS (display: none) sans le supprimer du DOM.
